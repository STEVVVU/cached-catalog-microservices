## Why the extra terminal requests remain unexplained

The run's count pattern is consistent with a terminal-arrival race, but the exact scheduling decision was not traced. The frozen [k6 2.3.0 constant-arrival-rate executor](https://github.com/grafana/k6/blob/v2.3.0/lib/executor/constant_arrival_rate.go#L290-L337) schedules arrivals by index and selects between the arrival timer and duration signal. The timer branch does not recheck the duration before starting its iteration. This source behavior provides a plausible explanation for an arrival at the 20-second boundary. The eight streams with an extra request span approximately 20 seconds from first to last start. The evidence does not establish which select branch won at runtime.

The original 39 errors and [original result](../evidence/focused-k6-20261024/result.json) remain alongside the corrected audit. The curated evidence retains all 15 native summaries and exact oracle JSON/CSV receipts as LF-only copies, with source and published-file hashes. Each compressed native stream's raw hash is recorded per cell in the manifest; the complete streams remain in the [hosted artifact](https://github.com/STEVVVU/cached-catalog-microservices/actions/runs/40126825830) and the local audit store. No native-run summary was filtered. An independent raw-stream calculation reconciled all three native trend counts and p50/p95/p99 values in every cell, including the extra-request cells; that calculation does not waive their fixed-count failures.

The corrected receipt persistence change fixes JSON round-trip verification when Python tuples decode as JSON lists. The separate k6 receipt-audit correction recognizes the observed custom code `OK`. Neither correction changes runtime code, the frozen JavaScript workload, thresholds, or campaign data. An independent design review rejected adding a request-budget guard as a repair for the prior campaign; no such guard or rerun was added. This evidence supports no native k6 confirmation of the Go results and no speedup or capacity claim.
